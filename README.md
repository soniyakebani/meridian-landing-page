# Meridian Tide 2 — landing page

Static front-end project. No build step, no dependencies.

```
meridian-landing-page/
├── index.html
├── css/
│   └── styles.css
└── assets/
    └── images/
        ├── hero-watch.svg
        ├── swimmer-underwater.svg
        ├── watch-side-profile.svg
        ├── coach-dashboard.svg
        ├── strap-buckle-closeup.svg
        └── bay-headland-buoy.svg
```

Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

Fonts (Space Grotesk, IBM Plex Sans) load from Google Fonts.
